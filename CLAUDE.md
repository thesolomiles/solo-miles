# Solo Miles

## Dev journal — read at the start of every session

At the **start of every solo-miles session**, read [journal.html](journal.html) to get
up to speed on recent progress. Before ending a session where meaningful work happened,
add or update **today's** entry:

- Entries are newest-first. Add a new date link at the **top** of the `<nav>` list and a
  new `<article>` block at the **top** of `<main>`, using `id="YYYY-MM-DD"`.
- If today's entry already exists, append bullet points to it rather than duplicating.
- Keep bullets concise — what changed and why, not a play-by-play.
